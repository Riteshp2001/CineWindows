# Support

## Start here

- Read the [project README](README.md) for setup, build, packaging, and feature information.
- Read the [documentation index](docs/README.md) and the user documentation under
  [`website/docs`](website/docs/README.md).
- Search [existing issues](https://github.com/Riteshp2001/CineWindows/issues) and
  [discussions](https://github.com/Riteshp2001/CineWindows/discussions).

## Ask for help

Use [GitHub Discussions](https://github.com/Riteshp2001/CineWindows/discussions) for setup questions, usage questions,
and ideas that are not yet actionable bug reports. Use the configured issue forms for
reproducible bugs, feature requests, and documentation problems.

Include the CineWindows version or commit, operating system, relevant Qt/libmpv details, exact
steps, logs, and screenshots when appropriate. Do not attach copyrighted media unless you have
permission to share it.

## Private requests

Security vulnerabilities belong in the [security process](SECURITY.md). Privacy requests and
licensing inquiries may be sent to [panditritesh2001@gmail.com](mailto:panditritesh2001@gmail.com). Support is provided
on a best-effort basis with no guaranteed response time.
