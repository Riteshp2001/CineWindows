CineWindows is a modern media player for Windows built on the Qt 6.8+ framework. It combines a native C++20 core with a fluid QML user interface and the powerful mpv playback engine to deliver high-performance video and audio playback with a refined desktop experience.

## Platform Support

CineWindows targets Windows 10 (build 1809+) and Windows 11. It uses Qt 6.8's platform abstractions for native title bar integration, high-DPI scaling, and Windows 11 Snap Layout compatibility. The installer is available as a portable ZIP or NSIS installer.

<Callout type="tip">
  CineWindows automatically detects your system DPI and scales the interface accordingly. For multi-monitor setups with mixed scaling factors, each window adjusts independently.
</Callout>
