CineWindows shortcuts are fully remappable from `Preferences > Shortcuts` (`Ctrl+/`). Player shortcuts mirror mpv's official defaults when CineWindows intercepts them for app behaviour or OSD; unlisted mpv defaults are forwarded directly to libmpv.

## Remapping Shortcuts

1. Press `Ctrl+/` to open the Shortcuts dialog
2. Click the edit icon next to any binding
3. Press the new key combination
4. Use the row reset button or `Reset all` to restore defaults

<Callout type="info">
  Custom bindings are serialised as a JSON string stored in the `input/keyBindings` preference. The Shortcuts dialog provides a visual editor — manual JSON editing is not recommended.
</Callout>

<Callout type="tip">
  If you have an existing `input.conf` in your mpv config directory, CineWindows loads it at startup via the `MpvConfig` loader. Key sequences in `input.conf` override the application defaults. The Preferences Shortcuts dialog shows warning badges when a sequence is also bound in `input.conf`.
</Callout>
