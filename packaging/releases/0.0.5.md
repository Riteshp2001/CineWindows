CineWindows 0.0.5 improves playback resume, media browsing, and desktop packaging.

## Playback

- Remembers playback positions by default while preserving an explicit opt-out.
- Saves resume state before stopping or replacing media and honors explicit restarts at zero.
- Resets shared OpenGL state before Windows video rendering and guards failed render contexts.
- Prevents Windows display-idle dimming while visible video is actively playing.

## Library

- Adds persistent included/excluded folders with exclusions taking precedence.
- Adds optional library-only browsing and individually customizable Places.
- Combines Recent Files and All Visits under one History navigation entry.
- Invalidates stale library scans when folder rules change, preserving existing library data.

## Packaging and Security

- Bundles PipeWire client modules, SPA plugins, configuration, and the C++ runtime in AppImages.
- Pins AppImage builds to Ubuntu 22.04 and rejects libraries requiring glibc newer than 2.35.
- Resolves the companion lint toolchain's minimatch and zod dependency audit findings.
- Includes the secure yt-dlp updating and thumbfast preview improvements prepared for 0.0.4.

Display, graphics-driver, and media-specific behavior can vary between systems. AppImages retain system glibc and graphics-driver dependencies.
