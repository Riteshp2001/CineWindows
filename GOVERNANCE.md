# Governance

CineWindows uses a maintainer-led governance model.

## Decision making

The primary maintainer has final responsibility for architecture, roadmap, releases, security,
licensing, moderation, and repository administration. Technical proposals are evaluated using
user impact, correctness, maintainability, compatibility, security, and consistency with the
project's license and direction.

Routine changes may proceed through a pull request. Broad behavior or architecture changes
should begin with an issue or discussion so constraints and alternatives can be reviewed before
implementation.

## Roles

- **Maintainer:** reviews and merges changes, manages releases, handles security reports, and
  enforces project policies.
- **Contributor:** proposes code, documentation, design, translation, testing, or issue analysis
  under the contribution terms.
- **Participant:** reports issues, asks questions, and joins discussions under the code of conduct.

Current role assignments are listed in [MAINTAINERS.md](MAINTAINERS.md). Governance questions
may be raised in [GitHub Discussions](https://github.com/Riteshp2001/CineWindows/discussions).
