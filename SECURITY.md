# Security Policy

Last reviewed: September 10, 2026.

## Supported versions

| Version | Security updates |
| --- | --- |
| Latest GitHub release | Supported |
| `main` | Supported for upcoming releases |
| Older releases | Not supported |

## Report a vulnerability

Do not open a public issue for a suspected vulnerability. Email
[panditritesh2001@gmail.com](mailto:panditritesh2001@gmail.com) with the subject `CineWindows security report`.

Include the affected version or commit, platform, impact, reproduction steps, and a minimal
proof of concept when safe. Remove credentials, private media, and unrelated personal data.

## Coordinated disclosure

The maintainer will acknowledge the report when practical, investigate it, and coordinate a
fix and disclosure plan based on severity. Please allow reasonable remediation time before
publishing details. Good-faith research that avoids privacy violations, data loss, service
disruption, and access beyond what is necessary to demonstrate the issue is welcome.

For ordinary bugs and support questions, use the [support policy](SUPPORT.md).
